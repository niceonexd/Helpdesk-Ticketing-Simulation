# Help Desk Ticketing System Simulation

## Project Overview
This project simulates a real-world IT Support help desk environment using a ticketing system.
It demonstrates handling, prioritizing, and resolving common L1 IT support issues.

## Tools Used
- Spiceworks Cloud Help Desk
- Windows OS
- Basic networking and troubleshooting tools

## Ticket Types Handled
- Login and account issues
- Email and Outlook issues
- Hardware and printer issues
- Network and VPN issues
- Software installation requests
- Access and permission issues

## Ticket Lifecycle
- Ticket creation
- Issue categorization and prioritization
- Troubleshooting and documentation
- Resolution and closure

## Skills Demonstrated
- Incident management
- Troubleshooting methodology
- Customer support communication
- Documentation and ticket handling
